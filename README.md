# موقع أوليفر فاشن — الخطوة 1: الأساس

هاد أول جزء من كود الموقع: صفحة رئيسية بسيطة تقرأ المنتجات من قاعدة بيانات حقيقية (Supabase) بدل ما تكون مكتوبة داخل الكود.

## الخطوات (بالترتيب)

### 1) إنشاء حساب Supabase (مجاني)
- روحي على supabase.com وسجلي حساب مجاني
- أنشئي مشروع جديد (New Project)، واختاري كلمة سر لقاعدة البيانات واحفظيها

### 2) تجهيز الجداول
- من لوحة Supabase: SQL Editor > New query
- افتحي ملف `supabase-schema.sql` الموجود بهاد المجلد، انسخي محتواه بالكامل، الصقيه، ودوسي RUN

### 3) أخذ المفاتيح
- من Project Settings > API، انسخي:
  - Project URL
  - anon public key
- افتحي ملف `.env.example`، سميه `.env.local`، وحطي القيمتين فيه

### 4) رفع المشروع على GitHub
- أنشئي حساب مجاني على github.com إذا ما عندك
- أنشئي repository جديد وارفعي هاد المجلد كامل فيه

### 5) النشر على Vercel
- سجلي دخول على vercel.com بحساب GitHub تبعك
- "Add New Project" واختاري الـrepository اللي رفعتيه
- بصفحة الإعدادات، ضيفي نفس القيمتين من خطوة 3 تحت "Environment Variables"
- دوسي Deploy

بعد هاي الخطوات رح يصير عندك رابط شغال (مثلاً oliver-fashion.vercel.app) وموقعك يقرأ من قاعدة بيانات حقيقية.
